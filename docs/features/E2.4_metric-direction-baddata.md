# E2.4 — Per-metric direction & bad-data handling

- **Epic:** E2 · User-Defined Metrics
- **Stage:** testing  *(built on `dev`, verified live — awaiting user click-through + merge)*
- **Platform:** web + iOS · **Depends on:** E2.2, E2.3

## 1. Summary
Generalizes C2 (bad-data handling) to **any** metric. Group ② becomes **one editable row per active metric**:
scoring **direction**, bad-data **policy** (penalize / carry-over / exclude / [compute — E3] / zero), and the
**penalty value**. Per-metric overrides live in `state.metricCfg` (pruned-on-default; `null` ⇒ baked-in
descriptor defaults), so the default 6 stay byte/behaviour-identical.

## 2. What shipped
- **`state.metricCfg`** `{key:{penalty?,badData?,direction?}}` + resolvers `cfgOf/effBadData/effDirection/
  effPenalty`. **Prune-on-default:** any edit that returns a metric to its descriptor default deletes the
  field; an empty entry is deleted; `{}` collapses to `null` (so a round-trip serializes `null`, not `{}`).
- **`#metricCfgRows`** (delegated listeners): label + direction control (**read-only badge** for the 6 /
  scoreFromDir:false; **editable toggle** only for catalog metrics) + policy `<select>` (options gated:
  *carry* needs a `carryKey`, *compute* needs `computeCapable` — off until E3) + a penalty `<input>` shown for
  `penaltyKey` metrics or when the policy is *penalize*. Focus-guarded rebuild (a focused penalty input isn't
  interrupted; a `<select>` change rebuilds so the penalty input toggles immediately).
- **Engine wiring:** `computeAllocation` passes `effPenalty(m)` + `effBadData(m)`-derived `nullExcludes`;
  `getFor()` gates carry on `effBadData==='carry'`; `computeCarryover`'s impute list is derived from the active
  carry-policy metrics. Penalty writes route by `penaltyKey` → `state.penalty` (the 6, single storage location)
  else `state.metricCfg[key].penalty`.
- **Persistence:** `metricCfg` round-trips through save/load/snapshot/restore/migrate (symmetric with `metrics`).

## 3. Acceptance criteria
- [x] Default 6: rows show correct direction/policy/penalty (PEG ↓/penalize/10 … mcap ↑/exclude); engine +
  `.penalized`/`.excluded` lists byte-identical.
- [x] Change a penalty → the `prem` tag text + blend update + persists.
- [x] Toggle a catalog metric's direction → contribution inverts; toggle back → `metricCfg` prunes to `null`.
- [x] Change EV carry→exclude → bank names drop from the EV average.
- [x] Edit-then-revert → `metricCfg` serializes `null`; undo/redo restores the versioned config.
