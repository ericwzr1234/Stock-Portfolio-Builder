# E2.3 — Choose your metrics (picker UI)

- **Epic:** E2 · User-Defined Metrics
- **Stage:** testing  *(built on `dev`, verified live — awaiting user click-through + merge)*
- **Platform:** web + iOS · **Depends on:** E2.2

## 1. Summary
A **✎ Choose metrics** picker (catalog grouped by category, checkboxes, per-book data-coverage badges) that
sets the active metric list, and the **generalization** of the whole Fundamentals surface — the weight inputs,
the per-theme metric table, and the methodology notes — to render one entry per **active** metric via
`metrics()`. **Byte-identical DOM at the default 6.**

## 2. What shipped
- **Picker modal** (`openMetricPicker`, reuses the theme-modal pattern): catalog grouped by Valuation /
  Profitability / Growth / Dividends / Health / Size / Momentum; the active set is checked; a coverage badge
  (`have/total` or **no data**) per metric when fundamentals are loaded. Toggling applies live; **≥1 metric
  enforced** (last checkbox blocked); picking exactly the default 6 normalizes to `state.metrics=null`.
- **Weights panel (① group):** static `#wGroup` wrapper holds a dynamic `#wInputs` (one labelled input per
  active metric) — **rebuilt only when the active set changes**, else value-only refresh with a **focus guard**
  (no caret loss); delegated `input`/`change` listeners on the stable wrapper; `readWeights` **mutates**
  `state.weights` (never reassigns) so activated keys survive. `#wEffNote` is `metrics()`-driven.
- **Per-theme table:** **Cap** is a special always-second column tied to `metricByKey('mcap')`; the other
  columns loop `metrics().filter(m=>m.key!=='mcap')`. The 6 keep bespoke cells (tags, `NM`, up/down class,
  editable overrides) for byte-identity; catalog metrics render via `fmtVal` (missing ⇒ `—`, never `NaN`).
- **Notes** driven by `metrics()` (semantically-equivalent muted copy). New picks seed a **10%** weight (only
  if absent). `startEdit` resolves the editor's live value via the descriptor's `overrideKey`.

## 3. Acceptance criteria
- [x] Default-6 Fundamentals DOM byte-identical (weight boxes, `wEffNote` `→ 20/20/20/15/10/15%`, per-theme
  tables incl. tags/editables/`NM`/up-down class).
- [x] Activate a metric → weight box + table column + config row appear, blend + drift shift, persists.
- [x] Deactivate → column/box/note removed, renormalize, persists. Cannot deactivate the last metric.
- [x] Coverage badges reflect the current book; a missing-data metric renders `—`, its names excluded.
- [x] Typing a weight updates live with no caret loss; delegated listeners survive rebuilds.
