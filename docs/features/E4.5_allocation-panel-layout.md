# E4.5 — Allocation-model panel layout

- **Epic:** E4 · Fundamentals/Screener redesign
- **Stage:** design → *(implement on `dev`, hold for user testing)*
- **Platform:** web + iOS

## Summary
Reorganize the two Fundamentals-tab cards so one card holds only the model *inputs* and the other holds the
*outputs/controls*, and tidy the alignment of the ①/② groups. **Final orientation (per user):** the
outputs/controls card is on the **left**, the inputs card on the **right**.

## Layout
**Left card ("Target vs current weight")** — outputs/controls. Keep the drift table, then **append below it**:
- the colored **allocation bar + legend**;
- **➕ New theme** / **↺ Restore default 5**;
- **↺ Reset to default 6** / **💾 Save preset** / preset `<select>` / delete;
- **Compute metrics from statements** toggle + **Compare sources** + coverage note.

**Right card ("Theme allocation model")** — inputs only:
- ① **Metrics** — a clean **2-column grid**: each cell = metric **name** + a weight **input** + `%`. A "Weight %"
  column header. Keep **✎ Choose metrics** + the effective-weight summary (`→ 20/20/20/15/10/15%`). **Drop the
  inline formula hints** ("(P/E ÷ Growth%)") — name only; the formula lives in a hover tooltip + the math notes.
- ② **Exception handling** — an **aligned 3-column grid**: each row = metric **name** (prefixed with a muted
  **↑/↓ direction cue**; the full "Higher/Lower is better" text is a hover tooltip) | handling-method **dropdown** |
  value **input** (only when *Penalize*; carries an `aria-label` since its column header is hidden on narrow widths).
  Column headers (Metric / When negative or missing / Value) so the controls line up. *(The old standalone
  "Direction" column was dropped to save width — the arrow cue replaces it and stays visible on touch/keyboard.)*
- ③ **Maximum weight per theme** — unchanged.
- The **"How the math works & data-quality notes"** collapsible stays at the bottom of the inputs card.

Cards stay side-by-side (grid2) on wide screens; stack on narrow. The two top cards are **equal width** (`1fr 1fr`,
14px gap) so they line up with the bottom per-theme cards. All existing behavior (weights, policies, picker,
presets, compute toggle, compare, theme add/restore/drift) is preserved — only DOM location + alignment change.

## Acceptance
- [ ] Left = ①②③ + math notes; right = drift + bar + legend + theme/preset/compute controls.
- [ ] Metric names + weight boxes aligned in 2 columns; exception rows aligned; no inline hints (tooltip kept).
- [ ] Every control still works from its new location; no console errors; renders on narrow widths.
