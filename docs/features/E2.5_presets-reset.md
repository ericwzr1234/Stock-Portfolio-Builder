# E2.5 — Presets / reset to the default 6

- **Epic:** E2 · User-Defined Metrics
- **Stage:** done  *(integrated to `main` 2026-07-01)*
- **Platform:** web + iOS · **Depends on:** E2.3, E2.4

## 1. Summary
A one-click **↺ Reset to default 6** and a small **named-preset** library so a whole metric model
(metrics + weights + exception handling) can be saved and recalled. Presets are a **user library** — they are
**NOT** captured by version history (undo/redo never adds/removes a preset), and neither reset nor load touches
the **theme cap** (it is theme-structure-scoped and N-adaptive).

## 2. What shipped
- **Controls** under the theme buttons: `↺ Reset to default 6`, `💾 Save preset`, a preset `<select>`, and a
  `✕` delete. Bound as static-id listeners at init.
- **`DEFAULT_CONFIG`** (weights derived from `DEFAULT_METRICS`, penalty kept in sync with the state literal).
  **`resetToDefault6()`** → `state.metrics=null`, `metricCfg=null`, weights/penalty = deep copies of the
  defaults (cap untouched; confirm dialog states cap is not reset).
- **`applyConfig(cfg)`** replaces `weights/penalty/metricCfg` **wholesale** (deep copies, no stale-key leak) and
  sets `metrics = validateMetrics(cfg.metrics)`. **`saveCurrentPreset`/`loadPreset`/`deleteSelectedPreset`/
  `renderPresetSelect`** manage `state.presets` (`[{name,config,savedAt}]`). `PresetConfig` = `{metrics:[{key}],
  weights, penalty, metricCfg}`.
- **Persistence:** `state.presets` saved/loaded (`sanitizePreset` drops structurally-malformed presets but keeps
  null-metrics = default-6 presets); **deliberately excluded** from `snapshotState`/`restoreVersion`/
  `migrateVersions`.

## 3. Acceptance criteria
- [x] Save a preset → appears in the select and survives reload.
- [x] Reset → snaps to the default 6 (weights 20/20/20/15/10/15, penalties 1000/10/50/200), cap unchanged,
  metrics `null`.
- [x] Load a preset → restores metrics + weights + penalties/direction exactly; re-renders.
- [x] Undo/redo does **not** add or remove presets (excluded from snapshots).
- [x] Delete removes it from the select and after reload.
