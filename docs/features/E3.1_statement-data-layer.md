# E3.1 — Statement fetch + cache (server)

- **Epic:** E3 · Statement-Driven Data · **Stage:** testing *(built on `dev`, verified live — held for user testing)*
- **Platform:** web + iOS · **Foundation card**

## Summary
A server data layer that loads the 3 financial statements per symbol from Yahoo's **`fundamentals-timeseries`**
endpoint (the old v10 `quoteSummary` statement modules are dead — verified). New `/api/statements` route + a
per-symbol cache; the client mirrors it with `web`/`native`/`ds` helpers.

## What shipped
- **`server.py`**: `_STMT_FIELDS` (30 Yahoo `quarterly*` type-keys → short line-item names), `_fetch_one_statement`
  (crumb-authed, `padTimeSeries=false`, **skips null reportedValues** so a padded gap can't break a TTM sum, **one
  crumb retry**, keeps up to 9 quarters — Yahoo caps at ~5), `fetch_statements_live` (parallel), `get_statements`
  (**per-symbol cache** `{sym:{ts,data}}`, `STMT_TTL=24h`, `STMT_NEG_TTL=6h` for the empty sentinel; lazy — only
  fetches missing/stale symbols). `/api/statements?symbols=…&force=` route.
- **Normalized shape:** `{sym, quarters:[{date, revenue, grossProfit, …, totalAssets, equity, totalDebt, fcf, …}],
  asOf, source:'live'|'empty'}` (oldest→newest). A name with no data returns the **clean-empty sentinel**
  (`quarters:[]`) so it is cached, not refetched every load, and the app falls back to pulled fields.
- **`www/index.html`**: `STMT_FIELD_MAP` (client mirror) + `webStatements`/`nativeStatements`(on-device
  timeseries fetch)/`dsStatements`/`loadStatements(syms,force)` → `state.statements`.

## Acceptance criteria
- [x] `GET /api/statements?symbols=AAPL,JPM` → AAPL 5 quarters of clean line items (no nulls), JPM 5 quarters
  (missing gross profit etc. — bank).
- [x] Per-symbol lazy cache; a second call within TTL doesn't hit Yahoo; a name that errored isn't cached (retries).
- [x] Empty sentinel cached under the shorter negative TTL. iOS `nativeStatements` returns the same shape.
