# E3.2 — Computed-metric engine (client)

- **Epic:** E3 · **Stage:** done *(integrated to `main` 2026-07-13)*
- **Platform:** web + iOS · **Depends on:** E3.1

## Summary
Compute each catalog metric **from the loaded statements** instead of reading Yahoo's pre-computed field. The
computed values overlay a **pulled base** (`state.pulled`), producing the same `state.fundamentals[sym].<field>`
the E2 getters read — so the whole model keeps working, now statement-sourced. Forward/market metrics stay pulled;
a missing statement input falls back to the pulled field. Per-field provenance in `state.metricSource`.

## What shipped (`www/index.html`)
- **Layering:** `state.pulled` = raw pulled fundamentals; `state.fundamentals` = a fresh copy of `state.pulled`,
  overlaid with computed metrics when `state.computeFromStatements`. `loadFundamentals` writes `state.pulled` then
  `rebuildFundamentals()`; `rebuildFundamentals()` rebuilds `state.fundamentals` + `state.metricSource` and calls
  `applyComputedMetrics()`. **`state.pulled` is never mutated** → the toggle reverts with no re-fetch.
- **`stmtTTM(sym)`** — TTM assembly: **sum of the last 4 quarters** for flows; **latest quarter** for the balance
  sheet; `avgBal = (equity at TTM-window start + latest)/2` for ROE/ROA; **YoY growth = latest Q vs year-ago Q**
  (needs 5 quarters — Yahoo's cap, and matches Yahoo's own `revenueGrowth` definition).
- **`computedMetrics(sym)`** computes pe, ev, evRev, ps, pb, dfcf, debtToEquity (×100, since the getter ÷100),
  currentRatio, quickRatio, gross/op/net margin, roe, roa, payout, revGrowth, earnGrowth + the raw operands
  (fcf/ebitda/revenue/cash/debt) the derived getters (pfcf/ebitdaMargin/fcfMargin/netCashPct) need. Every value is
  denominator-guarded (no NaN/Inf).
- **`STMT_PULLED_FIELDS`** (marketCap, price, mom, peg, forwardPE, beta, divYield) are **never** computed.

## Validation (live vs Yahoo's own numbers)
P/E, EV/EBITDA, gross/op/net margin, P/S, P/B, current ratio, Debt/Equity match **≤3%**. ROE/ROA use **average
equity/assets** and now match Yahoo. Divergences (quick ratio) are transparent methodology choices — the point of E3.

## Acceptance criteria
- [x] Computed values overlay `state.fundamentals`; sources tagged `computed`; model finite (Σ alloc = 1).
- [x] A bank (JPM) computes pe/ps/pb/roe but falls back to **pulled** for gross margin / current ratio.
- [x] Toggling `computeFromStatements` off reverts every field to the pulled value with no network call.
