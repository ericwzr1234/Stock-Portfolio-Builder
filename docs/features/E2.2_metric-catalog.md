# E2.2 — Metric catalog + compute layer

- **Epic:** E2 · User-Defined Metrics
- **Stage:** testing  *(built on `dev`, verified live — awaiting user click-through + merge)*
- **Platform:** web + iOS · **Depends on:** E2.1 (data-driven metric list)

## 1. Summary
Turns the *candidate catalog* into **data**. `METRIC_CATALOG` (in `www/index.html`) holds the 6 default
descriptors **verbatim** plus **21 inactive-by-default** catalog metrics; `DEFAULT_METRICS =
METRIC_CATALOG.filter(m=>m.defaultActive)`. Each catalog metric carries a getter/formula, a **direction**
(higher/lower better), a **group**, a **bad-data policy**, a **formatter**, and a score built by direction
(`dirScore`). `server.py` forwards the extra Yahoo fields the model needs. **Byte-identical at the default 6.**

## 2. What shipped
- **`catMetric()` builder** + `METRIC_CATALOG`: value (Fwd P/E, EV/Rev, P/S, P/B, P/FCF), profitability
  (gross/op/net/EBITDA/FCF margin, ROE, ROA), health/risk (Debt/Equity, current/quick ratio, net-cash, beta),
  growth (revenue, earnings), income (dividend yield [zero-policy], payout). ROIC / interest coverage / asset
  turnover / real buyback yield / R&D intensity are **deferred to E3** (need statement data) — omitted from the picker.
- **Compute layer:** `dirScore(m,x)` (higher ⇒ `max(0,x)`; lower ⇒ `x>0 ? 1/max(x,scoreFloor) : 0`),
  `scoreOf(m,x)` dispatches to the descriptor's own `score()` for the 6 (`scoreFromDir:false`) or `dirScore`
  for catalog metrics. `themeMetric()` kept its signature and gained a **null-penalty exclude guard** so a
  catalog metric with no penalty excludes bad values instead of computing `NaN`.
- **`server.py`** `_fetch_one_fundamental` + SEED fallback: ~21 additive, **null-safe** fields via `_rv`
  (missing ⇒ `None`, never fabricated). `debtToEquity` forwarded as Yahoo's PERCENT (JS getter ÷100). Raw TTM
  operands (`fcf/ebitda/revenue/cash/debt`) forwarded for JS-derived metrics (P/FCF, margins, net-cash).
  **Requires a server restart** (done).

## 3. Acceptance criteria
- [x] Default-6 engine byte-identical (maxDiff=0 on frozen inputs, before+after all edits + the server change).
- [x] New fields present + populated on live names; `None` where Yahoo lacks them.
- [x] A catalog metric activates and produces a valid, finite allocation (no `NaN`/`Inf`); derived getters
  null-safe (D/E correctly ÷100 → 2.82 on MA).
- [x] `divYield` non-payers score 0 (not excluded); higher-better negatives excluded, not fabricated.

## 4. Notes
Scope was the **catalog + compute + data layer**; the picker UI is E2.3, per-metric config is E2.4, presets E2.5.
E3 later swaps the *source* of each value from Yahoo fields to computed-from-statements at this same seam.
