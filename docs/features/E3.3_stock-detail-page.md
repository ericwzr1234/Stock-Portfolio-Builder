# E3.3 — Stock-detail page (UI)

- **Epic:** E3 · **Stage:** done *(integrated to `main` 2026-07-13)*
- **Platform:** web + iOS · **Depends on:** E3.2

## Summary
Click a ticker anywhere → a detail view showing its **3 statements × the last 4 quarters (+ a TTM column)** and a
**computed-metrics panel** (every catalog metric with its value + source: `calc` = from statements, `pulled` =
Yahoo market/forward-looking). Lazy-loads statements for names not yet fetched (e.g. Screener stocks).

## What shipped (`www/index.html`)
- **`openStockDetail(sym)`** — a modal (reuses the `#modalRoot` pattern); shows a loading state, lazy-loads
  statements (`loadStatements([sym])`), then `renderStockDetail(sym)`.
- **`renderStockDetail(sym)`** — header (price, market cap, TTM date, source mode); a metrics panel over
  `METRIC_CATALOG` (value via `m.getter`, source tag via `metricSourceOf`); the 3 statement tables from
  `STMT_DISPLAY` (income / balance / cash flow) × the last 4 quarters, with a **TTM column** for flows (summed;
  shares/EPS excluded) and point-in-time for the balance sheet. Missing statements → a fallback note; the metrics
  panel still shows the pulled values.
- **Click-through:** ticker cells carry `data-stock="${sym}"` in the **fundamentals table, Prices, and Screener/
  watchlist**; one delegated `main` click listener opens the detail, guarding `button/select/input/a/.editable/
  .reset/.swatch` (so inline edits, add/swap controls, and theme-name cells don't trigger it). `td.sym[data-stock]`
  gets a pointer cursor + hover underline.

## Acceptance criteria
- [x] Click AAPL in the fundamentals table / Prices / watchlist → detail opens; clicking an inline-edit value or a
  control in the same row does **not** open it.
- [x] 3 tables × 4 quarters + a correct TTM (flow TTM = sum of the 4 quarterly cells; balance = latest quarter).
- [x] Each metric value equals its fundamentals-table value; forward/market metrics tagged `pulled`, computed
  metrics tagged `calc`. A bank / no-statement name shows the fallback note without error.
